One-line excuse from a robot vacuum that missed a spot — a [make.fun](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) entry.

## The line

> My LiDAR swept that spot twice and filed it under floor's problem now — sensors don't lie, but dust does.

105 characters, one line.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. It writes the line to `/output/entry.txt`.
